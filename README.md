# AI Workplace Harassment Detection

This project uses Natural Language Processing (NLP) and a transformer model to detect workplace harassment from text statements.

## Features
- Detects Sexual Harassment
- Detects Verbal Abuse
- Detects Physical Threats
- Streamlit web interface for interaction

## Technologies Used
- Python
- PyTorch
- HuggingFace Transformers
- Streamlit

## How to Run

1. Clone the repository
2. Install requirements
